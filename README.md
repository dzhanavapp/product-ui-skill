# product-ui — скилл для Claude Code

Скилл, который превращает Claude Code в небольшую продуктовую команду: **тимлид + продуктовый дизайнер +
фронтенд-разработчик**. Он задаёт **процесс и планку качества** для создания веб-приложения — от первых вопросов
до проверенного продукта, которым приятно пользоваться.

Скилл не навязывает, как должен выглядеть продукт. Разделы, навигация, раскладка, палитра и шрифты определяются
вами и вашими референсами. Скилл отвечает за то, чтобы результат был быстрым, понятным, аккуратным и удобным
на всех устройствах, которые вы назвали.

## Что умеет

- **Начинает с вопросов, а не с кода.** Выясняет, для кого продукт, какую задачу он решает, на каких устройствах
  и в каких условиях им пользуются. Спрашивает про тему, шрифты (гротеск, с засечками, выразительный для заголовков),
  палитру и характер. Просит ссылки и скриншоты референсов и уточняет, что именно в них нравится.
- **Изучает предметную область.** Саб-агент разбирает ваши референсы и сильные продукты в той же нише: структуру,
  ключевые экраны, навигацию на разных устройствах, тексты, детали.
- **Составляет дизайн-план вместе с вами.** Он включает:
  - структуру и навигацию, выведенные из ваших сценариев и референсов;
  - палитру и роли шрифтов;
  - вайрфреймы для каждого типа устройства;
  - одну запоминающуюся деталь.

  План проверяется на шаблонность скиллом [frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)
  и утверждается вами до начала работы над кодом.
- **Закладывает фундамент качества:**
  - токены в одном месте и видимый фокус;
  - уважение к `prefers-reduced-motion`;
  - состояния загрузки той же формы, что и контент;
  - понятные пустые экраны и ошибки;
  - изображения, которые не сдвигают макет;
  - навигация с восстановлением прокрутки.
- **Делает продукт быстрым:**
  - три уровня кэша: на сервере (stale-while-revalidate), в браузере (с сохранением между визитами) и HTTP-заголовки;
  - бережёт лимиты внешних API.
- **Отвечает на действия мгновенно.** Оптимистичные обновления с «Отменить» и откатом при ошибке.
- **Делает ожидание понятным.** Подсказка становится подробнее со временем, а перегрузка сервера показывается
  как очередь, а не как ошибка.
- **Работает командой.** Экраны пишут параллельно саб-агенты с непересекающимися файлами по готовым брифам.
  Потом независимый ревьюер ищет баги, лишние запросы, проблемы вёрстки, доступности и текстов.
- **Проверяет глазами.** Скриншоты ключевых экранов на разных размерах, проверка того, что зависит от браузера,
  и честный отчёт: что проверено, а что нет.
- **Ведёт CLAUDE.md проекта.** Фиксирует архитектуру, дизайн-систему и правила, чтобы следующие сессии держали
  тот же уровень без повторных объяснений.

Стек по умолчанию для нового проекта — React, TypeScript, Vite, Tailwind CSS v4, [shadcn/ui](https://ui.shadcn.com),
TanStack Query. Если у вас свой стек или готовый проект, скилл работает в нём.

## Установка

### Вариант 1 — как плагин (рекомендуется)

```bash
claude plugin marketplace add dzhanavapp/product-ui-skill
```
```bash
claude plugin install product-ui@product-ui-skill
```

Обновление до свежей версии:

```bash
claude plugin marketplace update product-ui-skill
```

### Вариант 2 — копированием в папку скиллов

```bash
git clone https://github.com/dzhanavapp/product-ui-skill.git
```

macOS / Linux:

```bash
mkdir -p ~/.claude/skills && cp -r product-ui-skill/skills/product-ui ~/.claude/skills/
```

Windows (PowerShell):

```powershell
Copy-Item -Recurse product-ui-skill\skills\product-ui $HOME\.claude\skills\
```

Чтобы скилл действовал только в одном проекте, скопируйте папку в `.claude/skills/` этого проекта.

### Рекомендуемая зависимость

Скилл опирается на официальный [frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design).
Если его нет, product-ui подскажет, откуда его взять. Можно поставить заранее:

```bash
mkdir -p ~/.claude/skills/frontend-design && curl -sL https://raw.githubusercontent.com/anthropics/skills/main/skills/frontend-design/SKILL.md -o ~/.claude/skills/frontend-design/SKILL.md
```

## Как пользоваться

Скилл включается сам, когда вы просите создать приложение, сайт или панель или переделать интерфейс «красиво
и удобно». Можно вызвать явно:

```
/product-ui
```

Дальше по этапам:
0. **Опрос:** продукт, люди, устройства, визуальные предпочтения, референсы, данные и ограничения.
1. **Исследование** референсов и предметной области (саб-агент в фоне).
2. **Дизайн-план:** структура и навигация, токены, шрифты, вайрфреймы. Вы его утверждаете.
3. **Каркас** проекта.
4. **Фундамент:** токены, `DESIGN.md`, базовые компоненты, данные и кэш, оптимистичные действия, живое ожидание.
5. **Экраны** параллельно саб-агентами.
6. **Независимое ревью** и исправления.
7. **Проверка** на всех нужных размерах экрана и в разных браузерах, честный отчёт.
8. **CLAUDE.md** со ссылкой на скилл и дизайн-систему. Обновляется после каждого крупного изменения.

Если вернуться к проекту в новой сессии, Claude прочитает `CLAUDE.md` и `DESIGN.md` и продолжит по тем же правилам.

## Что внутри

```
skills/product-ui/
  SKILL.md                    этапы работы и требования к качеству
  references/
    intake.md                 вопросы перед дизайном
    stack-setup.md            стек по умолчанию, команды, деплой
    foundation-kit.md         токены, навигация, изображения, состояния, списки, разные браузеры
    data-and-caching.md       уровни кэша, лимиты API, оптимистичные действия, живое ожидание, очередь
    copy-guide.md             правила текстов и формулы состояний
    agent-briefs.md           брифы: исследователь, разработчик экранов, ревьюер, исполнитель правок
    qa-checklist.md           проверка перед сдачей
    design-md-template.md     шаблон дизайн-системы проекта
    claude-md-template.md     шаблон CLAUDE.md и правила его ведения
.claude-plugin/               манифесты плагина и каталога
```

## Настройка под себя

- Примеры текстов написаны для русскоязычных интерфейсов. Для другого языка поправьте `references/copy-guide.md`.
- Свои правила (например, «не пушить без просьбы» или «не включать звук при проверках») добавьте в раздел
  «Требования к качеству» в `SKILL.md`.
