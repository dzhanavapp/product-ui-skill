# product-ui — скилл для Claude Code

Скилл, который превращает Claude Code в небольшую продуктовую команду: **тимлид + продуктовый дизайнер +
фронтенд-разработчик**. С ним Claude строит веб-приложение не «рабочим прототипом», а продуктом уровня крупных
сервисов: быстрым, плавным, понятным и одинаково удобным на телефоне, планшете и большом экране.

Скилл вырос из реального проекта — личного онлайн-кинотеатра, где этот процесс дал результат, которым приятно
пользоваться: мгновенные повторные визиты благодаря кэшу, плавные переходы, аккуратные тексты и продуманная
мобильная версия.

## Что умеет

- **Начинает с вопросов, а не с кода.** Спрашивает, для кого продукт и где им будут пользоваться, тёмная или светлая
  тема, какие шрифты (гротеск, с засечками, выразительный для заголовков), какая палитра и характер. Просит ссылки
  и скриншоты референсов и уточняет, что именно в них нравится.
- **Изучает рынок.** Саб-агент разбирает, как устроены лидеры ниши: структуру разделов, главную, карточки, каталог,
  поиск, мобильные паттерны и тексты.
- **Строит дизайн-систему осознанно.** Работает вместе со скиллом [frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design):
  палитра из 4–6 цветов, роли шрифтов, раскладка, одна запоминающаяся деталь. Проверяет, не выглядит ли план
  шаблонно, и только потом пишет код.
- **Делает фундамент, который ощущается «дорого»:**
  - токены темы, фокус, `prefers-reduced-motion`;
  - UI-кит: картинки с плавным появлением, горизонтальные ленты со стрелками, скелетоны той же формы,
    понятные пустые состояния и ошибки;
  - адаптивная навигация: боковое меню на десктопе, колонка иконок на планшете, таб-бар на телефоне.
- **Делает всё быстрым:**
  - три уровня кэша: серверный на диске (stale-while-revalidate), в браузере (react-query с сохранением)
    и HTTP-заголовки;
  - бережёт лимиты внешних API: склеивает одинаковые запросы, ограничивает предзагрузку бюджетом.
- **Отвечает на действия мгновенно.** Оптимистичные обновления с тостом «Отменить», откат при ошибке.
- **Пишет живые тексты ожидания.** Подсказка меняется со временем: «Подключаемся» → «Ищем…» → «Ещё немного, почти
  готово» → «что можно сделать». Перегрузку сервера показывает как очередь, а не как ошибку.
- **Работает командой.** Страницы пишут параллельно саб-агенты с непересекающимися файлами по готовым брифам.
  Потом независимый ревьюер ищет баги, лишние запросы, проблемы вёрстки, доступности и текстов.
- **Проверяет глазами.** Скриншоты ключевых страниц на 1440, 768 и 360 px, отдельная проверка Safari и iOS
  и честный отчёт: что проверено, а что нет.
- **Ведёт CLAUDE.md проекта.** Фиксирует архитектуру, дизайн-систему и правила, чтобы следующие сессии держали
  тот же уровень качества без повторных объяснений.

Стек по умолчанию: React 19, TypeScript, Vite, Tailwind CSS v4, [shadcn/ui](https://ui.shadcn.com),
TanStack Query, React Router, lucide-react, sonner. Для API — Node.js (Express).

## Установка

### Вариант 1 — как плагин (рекомендуется)

Добавьте каталог этого репозитория в Claude Code и установите плагин:

```bash
claude plugin marketplace add dzhanavapp/product-ui-skill
```
```bash
claude plugin install product-ui@product-ui-skill
```

Обновление до свежей версии:

```bash
claude plugin marketplace update product-ui-skill
```

### Вариант 2 — копированием в папку скиллов

```bash
git clone https://github.com/dzhanavapp/product-ui-skill.git
```

macOS / Linux:

```bash
mkdir -p ~/.claude/skills && cp -r product-ui-skill/skills/product-ui ~/.claude/skills/
```

Windows (PowerShell):

```powershell
Copy-Item -Recurse product-ui-skill\skills\product-ui $HOME\.claude\skills\
```

Чтобы скилл действовал только в одном проекте, скопируйте папку в `.claude/skills/` этого проекта.

### Рекомендуемая зависимость

Скилл опирается на официальный [frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design).
Если его нет, product-ui сам подскажет, откуда его взять. Можно поставить заранее:

```bash
mkdir -p ~/.claude/skills/frontend-design && curl -sL https://raw.githubusercontent.com/anthropics/skills/main/skills/frontend-design/SKILL.md -o ~/.claude/skills/frontend-design/SKILL.md
```

## Как пользоваться

Скилл включается сам, когда вы просите создать приложение, сайт или панель, переделать интерфейс «красиво
и удобно» или сделать «как у больших сервисов». Можно вызвать явно:

```
/product-ui
```

Например: «Сделай веб-приложение для учёта тренировок. Хочу как у Strava, тёмную тему и чтобы удобно было с телефона».

Дальше по шагам:
1. **Опрос:** продукт, аудитория, тема, шрифты, цвета, референсы (ссылки и скриншоты).
2. **Исследование** лидеров ниши (саб-агент в фоне).
3. **Дизайн-план:** палитра, шрифты, раскладка, главная деталь. Вы его утверждаете.
4. **Каркас:** Vite + React + Tailwind + shadcn/ui, кэш, роутинг.
5. **Фундамент:** токены, UI-кит, данные и кэш, оптимистичные действия, живое ожидание, `web/DESIGN.md`.
6. **Страницы** параллельно саб-агентами.
7. **Независимое ревью** и исправления.
8. **Проверка** на 1440, 768 и 360 px, Safari и iOS, честный отчёт.
9. **CLAUDE.md** со ссылкой на скилл и дизайн-систему. Обновляется после каждого крупного изменения.

Если вернуться к проекту в новой сессии, Claude прочитает `CLAUDE.md` и `web/DESIGN.md` и продолжит в том же стиле.

## Что внутри

```
skills/product-ui/
  SKILL.md                         процесс из 8 этапов и принципы, которые нельзя нарушать
  references/
    intake.md                      вопросы перед дизайном (тема, шрифты, цвет, референсы, данные)
    stack-setup.md                 стек, точные команды, грабли shadcn CLI, деплой
    foundation-kit.md              токены и UI-кит: картинки, ленты, навигация, баннер, советы для плеера и Safari
    data-and-caching.md            три уровня кэша, лимиты API, оптимистичные обновления, живое ожидание, очередь
    copy-guide.md                  правила текстов и формулы для загрузки, пустых экранов, ошибок, успеха
    agent-briefs.md                брифы: исследователь, разработчик страниц, ревьюер, исполнитель правок
    qa-checklist.md                проверка перед сдачей: размеры экрана, Safari/iOS, API, что нельзя делать
    design-md-template.md          шаблон дизайн-системы проекта (web/DESIGN.md)
    claude-md-template.md          шаблон CLAUDE.md и правила его ведения
.claude-plugin/                    манифесты плагина и каталога для установки одной командой
```

## Настройка под себя

- Тексты и примеры написаны для русскоязычных интерфейсов. Для другого языка поправьте `references/copy-guide.md`.
- Шрифты, цвета и стек в `foundation-kit.md` — проверенные значения по умолчанию, а не догма: на этапе опроса
  скилл подбирает их под ваш продукт.
- Свои правила (например, «никогда не пушить без просьбы» или «не включать звук при проверках») добавьте в раздел
  «Принципы» в `SKILL.md`.
