# Проверка перед сдачей

## Автоматически
- [ ] `npx tsc --noEmit -p tsconfig.app.json` без ошибок; `npm run build` проходит.
- [ ] Тесты логики (`node --test` / vitest) — для всего, что парсит, ранжирует, кэширует, ограничивает.
- [ ] grep по `src/` на техно-слова продукта и английские остатки («Close», «Loading», «Error»).

## Глазами (браузерная панель, `resize_window`)
Каждая ключевая страница на **1440, 768, 360 px** + после `location.reload()` (кэш из localStorage):
- [ ] Нет горизонтальной прокрутки страницы; ленты не прокручиваются по вертикали (`scrollHeight === clientHeight`).
- [ ] Кнопки не переполняются на 360 px; липкие панели не перекрывают таб-бар; тосты над таб-баром.
- [ ] Скелетоны совпадают по форме с контентом; картинки появляются плавно, без сдвигов.
- [ ] Пустые состояния и ошибки — с понятным текстом и действием.
- [ ] Фокус с клавиатуры виден; Esc закрывает диалоги; «Назад» возвращает на ту же позицию прокрутки.
- [ ] Скриншот делай после ожидания загрузки (смена слайдов/ленивые картинки дают ложную пустоту — проверяй
      `img.complete/naturalWidth` через JS, прежде чем считать баг).
- [ ] После правок фронтенда — полная перезагрузка страницы (смена hash не подгружает новый бандл).

## Через API (то, что нельзя кликнуть)
- [ ] Основные сценарии curl'ом: создание/удаление, перегрузка (503 → очередь), авторизация (401 без входа).
- [ ] Повторный запрос попадает в кэш (замер времени / счётчик реальных запросов к внешнему API).
- [ ] Долгие операции отменяются и чистят ресурсы (файлы, процессы, память).

## Нельзя
- Включать звук/видео у пользователя — громкость 0 или проверка через API.
- Тратить лимиты платных API проверками — один запрос на эндпоинт, дальше из кэша.
- Писать «проверено», если не проверял: в отчёте отдельно «проверено» и «не проверено (почему)».

## Safari / iOS (если есть медиа, загрузка файлов, полноэкранные режимы)
- [ ] Видео: MP4 с Range либо HLS; MKV/WebM и fMP4-поток без Range Safari не играет.
- [ ] Autoplay со звуком запрещён без жеста — есть явная кнопка «Смотреть».
- [ ] `100svh`, `env(safe-area-inset-*)`, `playsInline`, полноэкранный режим через `webkitEnterFullscreen` на iPhone.
