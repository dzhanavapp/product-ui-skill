# Проверка перед сдачей

## Автоматически
- [ ] Проверка типов без ошибок, сборка проходит.
- [ ] Тесты на логику, которая разбирает, ранжирует, кэширует или ограничивает.
- [ ] Поиск по коду внутренних терминов и английских остатков (см. copy-guide.md).

## Глазами (браузерная панель, `resize_window`)
Каждый ключевой экран на широком (~1440), среднем (~768) и узком (~360) экране — или на тех размерах, которые
важны для продукта, — а также после полной перезагрузки страницы (данные из кэша):
- [ ] Нет горизонтальной прокрутки страницы; внутри горизонтальных блоков нет вертикальной прокрутки
      (`scrollHeight === clientHeight`).
- [ ] Ничего не выходит за край на узком экране; фиксированные элементы не перекрывают контент и уведомления.
- [ ] Скелетоны совпадают по форме с контентом; изображения появляются плавно, без сдвигов.
- [ ] Пустые состояния и ошибки — с понятным текстом и действием.
- [ ] Фокус с клавиатуры виден; Esc закрывает диалоги; «Назад» возвращает на прежнюю позицию прокрутки.
- [ ] Делай скриншот только после загрузки. Ленивые картинки и анимации дают ложную пустоту, поэтому прежде чем
      считать это багом, проверь через JS (`img.complete`, `naturalWidth`).
- [ ] После правок фронтенда делай полную перезагрузку: смена адреса внутри приложения не подгружает новый код.

## Через API (то, что нельзя кликнуть)
- [ ] Основные сценарии запросами: создание и удаление, перегрузка (503 → очередь), ограничение доступа (401).
- [ ] Повторный запрос попадает в кэш: замер времени или счётчик реальных запросов к внешнему API.
- [ ] Долгие операции отменяются и освобождают ресурсы (файлы, процессы, память).

## Нельзя
- Включать звук или видео у пользователя: проверяй с нулевой громкостью или через API.
- Тратить лимиты платных API проверками: один запрос на эндпоинт, дальше из кэша.
- Писать «проверено», если не проверял. В отчёте — отдельно «проверено» и «не проверено (почему)».

## Разные браузеры (Safari / iOS и др.)
- [ ] Всё, что зависит от браузера, проверено или явно помечено как непроверенное: медиаформаты, автозапуск звука,
      полноэкранный режим, единицы высоты экрана, безопасные зоны, загрузка и скачивание файлов.
