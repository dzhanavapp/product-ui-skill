# Тексты интерфейса

Слова — часть дизайна. Ориентир — Airbnb, Okko, Кинопоиск: коротко, по-человечески, без техники.

## Правила
- Sentence case, без КАПСА, без «бровей» над заголовками, без «→» в кнопках, без подсветки одного слова в заголовке.
- Кнопка = глагол того, что произойдёт: «Смотреть», «Продолжить», «Сохранить», «Показать ещё», «Сбросить фильтры»,
  «Повторить», «Отменить». Действие сохраняет имя по всему пути (кнопка «Опубликовать» → тост «Опубликовано»).
- В основном интерфейсе — язык пользователя, не системы: «вариант», «источник», «открывается быстро», а не
  «раздача/сиды/пиры/magnet/ffmpeg/кэш/токен». Технику — только в Настройках/Загрузках и простыми словами.
- «Вы» со строчной (или «ты», если так решили на опросе) — единообразно везде.
- Числа и единицы по-русски: «4,2 ГБ», «1 ч 25 мин», «осталось 23 мин», правильные склонения
  (`plural(n, 'фильм', 'фильма', 'фильмов')`). Не «S2 E5» — «2 сезон, 5 серия».

## Состояния
| Состояние | Формула | Пример |
|---|---|---|
| Загрузка | скелетон без текста; если дольше — живая подсказка | «Подключаемся» → «Ищем, где посмотреть» → «Ещё немного, почти готово» |
| Пусто | приглашение к действию + кнопка | «Здесь появятся фильмы, которые вы отметите» · [Перейти в каталог] |
| Ничего не найдено | что случилось + как исправить | «Ничего не нашлось. Попробуйте изменить запрос или сбросить фильтры.» |
| Ошибка | что случилось + что делать + кнопка, без извинений | «Не удалось загрузить. Нет связи с сервером — проверьте подключение.» · [Повторить] |
| Перегрузка | очередь, а не отказ | «Сейчас много желающих. Запустим, как только освободится место» |
| Долго | что можно сделать | «Отвечают медленно. Можно подождать или выбрать другое качество» |
| Успех | короткий тост с отменой | «Добавлено в «Буду смотреть»» · [Отменить] |

## Проверка текстов
Перед сдачей пройди grep по `src/` на техно-слова продукта (составь список на старте) и на английские остатки
(«Close», «Loading», «Error»), на «...»/«..» и двойные точки в склейке сообщений сервера.
