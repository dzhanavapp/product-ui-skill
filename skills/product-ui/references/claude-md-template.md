## Правила ведения
- После этапа, который поменял архитектуру, правь соответствующий абзац, а не дописывай противоречия в конец файла.
- Если пришли чужие коммиты (с другого устройства или из другой сессии), сверь CLAUDE.md с кодом.
- Держи файл в пределах ~150 строк. Подробности — в DESIGN.md, README и комментариях в коде.
