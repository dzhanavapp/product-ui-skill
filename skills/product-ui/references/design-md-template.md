# Шаблон web/DESIGN.md

Заполни под продукт. Это источник правды для саб-агентов и будущих сессий — коротко и императивно.

```markdown
# <Продукт> — дизайн-система «<название темы>»

<Одна строка: что за продукт и какое ощущение даёт интерфейс. Ориентиры: <референсы>, без копирования.>

## Токены (src/index.css, <тема>)
- Фон `bg-background` <hex>, поверхности `bg-surface` <hex>, `bg-elevated` <hex>.
- Текст `text-foreground`, вторичный `text-muted-foreground`.
- Главная кнопка — <цвет> (`<Button>` default). Вторичная — `variant="secondary"`.
- Акцент `<имя>` — ТОЛЬКО <прогресс, активный пункт, фокус, …>. Не для декора.
- Радиусы: карточки `rounded-lg`, главные CTA `rounded-full`, панели `rounded-xl`.

## Типографика
- Заголовок страницы — `<PageTitle>` (`font-heading` = <шрифт>), только для заголовков страниц/героев.
- Остальное — <шрифт текста>. Заголовки секций — `<Section title>`.
- Без КАПСА, без «бровей», без «→», без подсветки одного слова.

## Компоненты (`@/components/<ui-kit>`) — используй, не дублируй
<список: Img, карточки, Rail, Section, PageTitle, Grid, LoadMore, EmptyState, ErrorState, …>
shadcn/ui — `@/components/ui/*`. `ResponsivePanel` — шторка на телефоне / боковая панель на десктопе.

## Данные (`@/lib/<data>`) — react-query, кэш сохраняется в браузере
<хуки и их staleTime>. Оптимистичные списки — <модуль> (`toggle` с тостом и отменой).
Лимит внешних API: <цифра> — не делай лишних запросов, не уменьшай staleTime.

## Раскладка
- Контент внутри `<main>` с `px-4 sm:px-6 lg:px-10`; full-bleed — `-mx-4 sm:-mx-6 lg:-mx-10`.
- Телефон: нижний таб-бар (отступ учтён). 360–2560 px.

## Тексты
- Глаголы действия: <список>. Пустые состояния — приглашение к действию. Ошибки — что случилось и что делать.
- Без техники в основном интерфейсе: <запретные слова> → <замены>.
- Ожидание живое: статус → пояснение → «Ещё немного…» → что можно сделать (`@/lib/wait`).

## Качество
- Скелетоны той же геометрии, без спиннеров на сетках. Видимый фокус, aria-label у иконок-кнопок, reduced-motion.
- Без анимаций «появления» секций; движение — только ответ на действие.
- `npx tsc --noEmit` без ошибок.
```
